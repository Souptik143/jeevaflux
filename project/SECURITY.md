# Security Policy

## Scope

Security issues involving the JeevaFlux code, mobile application, device
communication, synchronization or documentation should be reported privately
to the project maintainers.

## Security Priorities

- Authentication
- Secure transport
- Credential protection
- Data minimization
- Consent management
- Local protection of sensitive records
- Access control
- Auditability

## Sensitive Data

Do not commit real users' health data, identifiers, tokens, credentials,
location histories or other private information to this repository.

Use synthetic or de-identified examples for demonstrations.
