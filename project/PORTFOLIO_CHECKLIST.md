# JeevaFlux GitHub Portfolio Checklist

## Before Publishing

### Identity
- [ ] Add final team member names/roles
- [ ] Add final project logo
- [ ] Add final contact/social links
- [ ] Add official SIH information if permitted

### Evidence
- [ ] Add actual wearable/prototype photos
- [ ] Add mobile UI screenshots
- [ ] Add measured sensor results
- [ ] Add actual model benchmark results
- [ ] Add actual battery/latency measurements
- [ ] Add demo video link

### Code
- [ ] Add real source code
- [ ] Add setup instructions
- [ ] Add hardware wiring/BOM only if finalized
- [ ] Add model files or download instructions
- [ ] Add tests

### Data
- [ ] Add dataset sources
- [ ] Verify licenses
- [ ] Remove real health/personal data
- [ ] Add preprocessing documentation

### Claims
- [ ] Label estimates as estimates
- [ ] Label proposed features as proposed
- [ ] Do not claim clinical validation without evidence
- [ ] Do not claim regulatory approval without approval
- [ ] Document known limitations

### Presentation
- [ ] Add slide-derived images to appropriate folders
- [ ] Crop panels rather than repeating full slides
- [ ] Add architecture SVGs
- [ ] Add project screenshots
- [ ] Pin README
