# Risk Register

| Risk | Impact | Mitigation |
|---|---|---|
| Sensor inaccuracies | High | Calibration, quality checks, fusion |
| Motion artifacts | High | Motion-aware preprocessing |
| False alerts | High | Tiered alerts, personalization, validation |
| Missed events | High | Multimodal validation and conservative safety design |
| Battery depletion | High | Low-power scheduling and battery warnings |
| Connectivity loss | Medium | Local inference + store-and-forward |
| Model bias | High | Diverse validation and subgroup analysis |
| Privacy breach | High | Local processing, encryption, access control |
| Poor usability | Medium | Human-factors testing |
| Supply chain | Medium | Multiple component alternatives |
| Regulatory uncertainty | High | Early regulatory/clinical consultation |
