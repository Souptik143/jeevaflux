# JeevaFlux Research Plan

## Research Questions

1. Can multimodal physiological + environmental signals improve early-warning
   performance over isolated signals?
2. How much personalization improves detection while avoiding unsafe threshold
   drift?
3. Can lightweight models meet the memory, latency and power constraints of the
   target edge hardware?
4. How robust is the system during motion, sensor dropout and connectivity loss?
5. Can warnings be made understandable without creating excessive alert fatigue?

## Work Packages

### WP1 — Sensing
Characterize sensor quality, calibration and failure modes.

### WP2 — Signal Processing
Develop filtering, quality checks and windowed feature extraction.

### WP3 — Edge AI
Evaluate lightweight anomaly/risk models and optimize for edge execution.

### WP4 — Sensor Fusion
Combine physiological, environmental and context signals.

### WP5 — Personalization
Develop and validate a user baseline strategy.

### WP6 — Mobile
Build status, trend, alert and history workflows.

### WP7 — Offline Resilience
Implement local storage and synchronization recovery.

### WP8 — Validation
Measure accuracy, false alerts, warning lead time, power, latency and usability.
